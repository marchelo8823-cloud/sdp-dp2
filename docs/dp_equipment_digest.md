## 2. ДРУ: требования NavDP4000 (rev4, RUS) → наш аллокатор

| Требование | У нас |
|---|---|
| Набор 0→50% тяги ≤ 10 с | мгновенно (нет динамики привода) — **добавить** |
| Реверс тяги 100%→100% ≤ 15 с | то же |
| ВРК: скорость поворота винта ≥ 2 об/мин | — |
| **Азимутальная: поворот ≥ 12°/с** (2 об/мин) | `az_rate=10°/с` — слегка пессимистично, ок |
| Рассогласование угла азимута ≤ 2° (≤ 1° с АР) | идеальный трекинг — **добавить серво-ошибку** |
| Руль: перекладка ≥ 5°/с | руля нет |

**Вывод:** следующая итерация реализма — модель привода ДРУ: динамика набора
тяги (PT1 ~3–5 с), реверс ≤ 15 с, серво-ошибка азимута ±1–2°. Это сделает
HIL и trials ближе к приёмо-сдаточным испытаниям.

5. Сверка с модулями «ПРОЕКТ СДП СВОЙ» (Alarms, Sensors, Position References)
