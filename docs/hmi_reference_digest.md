# Дайджест референсного пульта СДП (8 экранов)

Источник: `Пульт СДП — новый экран.html` (Vue-приложение, SVG-отрисовка,
получено от пользователя 18.11.2026). Документ фиксирует лучшие решения
чужого дизайна и что из этого перенесено/планируется в SDP-DP2.

## Экраны референса

1. **Пульт СДП (удержание позиции)** — главный экран
2. **Вкладка «Опорные системы»** — отбор и веса PRS/гиро/ветра
3. **Счисление курса** — деградация при потере гирокомпасов
4. **Упор снят, нет курса** — терминальное состояние
5. **Удержание позиции** (вариант)
6. **Счисление положения** — удержание по модели без PRS
7. **Сравнение с действующими СДП** — матрица функций
8. **Своё рабочее место** — настраиваемые раскладки панелей

## Ключевые решения референса

### Деградационные состояния (самое ценное)
- **Счисление курса**: нет данных всех гирокомпасов N с → курс по
  счислению, обратный отсчёт «упор будет снят через X с».
- **Упор снят — нет курса**: команды движителям 0 %, баннер
  «автоматика не держит судно, нужно ручное управление».
  Возврат только руками: «Ожидание» → снова «Позиция», само
  удержание не включится.
- **Счисление положения**: нет систем положения → удержание по модели,
  «вероятный уход до 12 м и растёт» — явная оценка неопределённости.
- Блок **«ЧТО ДЕЛАТЬ»** — пошаговая подсказка оператору под каждое
  состояние.

### Опорные системы (вкладка)
- Отбраковка PRS по тестам: замирание, разброс («разброс 1,9 м больше
  предела 1,5 м — система отбракована»), скачок, прогноз, медиана.
- Таблица: система / принцип / состояние / причина / вес / СКО /
  до оценки; «для класса 2 — не меньше трёх, не все одного принципа».
- Круги СКО за 60 с относительно оценки ядра, предел медианы 5 м.
- Гирокомпасы: шкала отклонения от медианы.

### Главный экран
- Шапка: режим, отклонение, курс, загрузка %, тревоги, МСК.
- План: заданная точка и след за 5 мин, кольца пределов (3/5 м),
  «вероятный уход», ветер, внешнее возмущение (кН).
- Jog заданной точки: шаг 1 м, кнопки N/S/W/E + «Перенести точку сюда».
- Среда: ветер истинный/от носа/от правого борта, волнение по качке,
  крен/дифферент.
- Загрузка движителей за 5 мин, красная линия 80 %.
- Смена режима — повторное нажатие за 3 с (защита от случайности).
- Режимы: Ожидание / Автокурс / Автоположение / Джойстик / Пауза.

### Сравнение с действующими СДП (матрица функций)
Режимы: ручная ось в автоположении, мягкое удержание (радиус + закон
усиления), наименьшая мощность/флюгер (курс на равнодействующую среды),
движение по маршруту, следование за целью, независимый джойстик
(РС 8.9.4 — для всех классов), центр вращения / усиление / скорость
разворота. Энерго: ГРЩ-1/ГРЩ-2, кВт.

### Рабочее место
Перетаскивание панелей по ячейкам, наборы («Удержание у платформы»,
«Подход к объекту»), сохранение для поста и оператора, нужная панель
сама открывается при тревоге.

## Перенесено в SDP-DP2 (18.11.2026)

- Деградационные состояния в ядре `sdp/hmicore.py`: счисление курса
  (обратный отсчёт 4 с), снятие упора, счисление положения с моделью
  «вероятного ухода», ручное восстановление упора (`thrust_restore`).
- Баннер деградации + подсказка «ЧТО ДЕЛАТЬ» в QML-HMI.
- Jog заданной точки (N/S/W/E, шаг 1 м) и курса (±1°/±10°).
- Ветер от носа / от правого борта в панели Wind.
- Кнопки инструктора — переключатели отказ ↔ возврат агрегата.

## Очередь на следующие итерации

- [ ] Отбраковка PRS по тестам (замирание/разброс/скачок) + веса систем
- [ ] Вкладка «Опорные системы» (таблица + круги СКО)
- [ ] Загрузка движителей за 5 мин с линией 80 %
- [ ] Двойное нажатие для смены режима (3 с)
- [ ] Режимы: Ожидание / Автокурс / Джойстик / Пауза
- [ ] Мягкое удержание, наименьшая мощность (флюгер)
- [ ] Настраиваемые раскладки панелей (своё рабочее место)
- [ ] Крен/дифферент (MRU) в панель среды — после модели MRU
