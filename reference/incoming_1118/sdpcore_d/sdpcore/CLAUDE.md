# Ядро СДП — общие правила для всех агентов

Проект: ядро системы динамического позиционирования (СДП). Цель — удержать судно в заданной точке и на заданном курсе по данным внешних датчиков, управляя движителями. C++17, только заголовочные файлы в `include/dp`, рабочая программа `apps/sdp_run.cpp`, редактор данных судна `shipedit/` (Qt 6). Подробности — в `README.md` и `ЗАПУСК.md`.

## Язык и оформление
- Все отчёты, комментарии, задачи и сообщения — по-русски. Термины интерфейса — по-русски.
- Ограничения и риски отмечаются знаком ⚠.
- Пароли, ключи и токены не пишутся никогда и нигде: ни в коде, ни в отчётах, ни в комментариях. Если нужно упомянуть — только название, без значения.

## Главное правило
- **Ничего не меняется без явного одобрения владельца.** Агенты не отправляют изменения в основную ветку. Любое изменение — только отдельной веткой и предложением изменений (pull request), которое принимает владелец.
- Сначала анализ и предложение, потом изменение.

## Сборка и проверка
```
cmake -S . -B build -DSDP_BUILD_EDITOR=ON      # без Qt: без -DSDP_BUILD_EDITOR=ON
cmake --build build -j
cd build && ctest --output-on-failure
```
- Сценарии для ядра: `./build/sdp_run --script tests/scenarios/<файл>.txt --status 30`.
- Редактор без экрана: `QT_QPA_PLATFORM=offscreen ./build/shipedit/sdp_ship <книга.xlsx> --screenshot снимок.png`.
- Данные судна для проверок: `data/Данные_судна_пример.xlsx`, имитатор: `data/Данные_имитатора_пример.xlsx`.

## Что важно для безопасности судна
- Удержание при потере датчиков не снимается само: ядро держит по счислению с тревогой. Не менять это без решения владельца.
- Потеря курса: 2 с без данных гирокомпасов, ещё 2 с счисления (HDG_DR), затем нулевой упор (HDG_LOST) — как в K-Pos; решение владельца 16.11.2026. После возврата систем положения — плавный возврат в заданную точку (POS_RETURN), если оператор не выбрал «держать здесь» (команда `here`). Движитель без обратной связи через 2 с выводится из распределения упоров (THR_FB_LOST). Подробно — `README.md`, «Потеря положения и курса».
- Ядро не подставляет заглушки вместо данных судна: пустое обязательное поле — ошибка.
- Любое изменение регулятора, распределителя упоров, оценки состояния или порогов тревог считается изменением, влияющим на безопасность: его проверяет тестировщик, и оно отмечается в отчёте отдельно.
